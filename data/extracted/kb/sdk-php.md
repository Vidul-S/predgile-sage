# PHP SDK

_Section: Developers_ · _Last updated: 2026-01-03_

The official PHP SDK wraps the Paperkite API.

- Package: `paperkite/paperkite-php`.
- Minimum PHP version: 8.1.
- Install: `composer require paperkite/paperkite-php`.
- Async support: no.
- All SDKs send idempotency keys automatically.
