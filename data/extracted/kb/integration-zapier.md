# Paperkite for Zapier

_Section: Integrations_ · _Last updated: 2025-01-15_

The Zapier integration connects Paperkite to your automation workflow.

- No plugin is needed; connect with your API key.
- Subscriptions: supported.
- Minimum Paperkite plan: Starter.
- Data sync: real time.

1. Open **Settings > Integrations**.
2. Select Zapier and sign in.
3. Choose the data to sync and save.
