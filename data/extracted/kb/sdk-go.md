# Go SDK

_Section: Developers_ · _Last updated: 2026-01-06_

The official Go SDK wraps the Paperkite API.

- Package: `github.com/paperkite/paperkite-go`.
- Minimum Go version: 1.20.
- Install: `go get github.com/paperkite/paperkite-go`.
- Async support: yes.
- All SDKs send idempotency keys automatically.
